# Portfolio Launch 4 — GitHub Publication & Deployment Preparation

This milestone prepares the polished application for a public repository and controlled live demo without changing product features.

## Added

- production Next.js standalone image
- production FastAPI image without development dependencies
- same-origin HTTPS Caddy reverse proxy
- production Compose topology with private database/Redis/Ollama services
- sanitized production environment template
- GitHub CI for repository safety, backend static quality and frontend quality/build
- Dependabot configuration
- pull-request checklist
- release preflight script and Make targets
- GitHub publishing guide
- live demo deployment guide
- final release checklist

## Deliberately not automated

Actual DNS, cloud/VPS creation, secrets, administrator credentials and GitHub repository creation remain manual because they require owner-controlled accounts and credentials.
