# Portfolio Launch 1 — Group 1: Product UI Foundation

This pass establishes the production-facing visual direction for the public portfolio build without changing backend/API behavior.

## Changes

- Product identity updated to **Cortexa AI Knowledge Platform**.
- Development/milestone wording removed from the primary homepage experience.
- Enterprise positioning: RAG, knowledge management, AI quality and operations.
- Global visual tokens and reusable Tailwind component primitives added.
- Homepage hero rebuilt for portfolio screenshot readiness.
- Authenticated navigation simplified around Overview, Chat, Knowledge, Memory, Tools and Admin.
- Chat chrome upgraded to a calmer enterprise assistant presentation.
- Admin navigation grouped by Workspace, Knowledge, AI Quality, Operations and Administration.
- Unstable/experimental Agents navigation is no longer promoted in the admin sidebar.
- Admin shell/header/sidebar spacing, contrast and responsive presentation improved.
- Metadata title/description updated for the product positioning.

## Non-goals

No backend logic, API contracts, migrations, queue behavior, RAG behavior, authentication policy, evaluation scoring, or analytics calculations were changed.

2. Chat and knowledge/document surfaces.
3. Evaluations, feedback and jobs.
4. Responsive/accessibility and final screenshot polish.
