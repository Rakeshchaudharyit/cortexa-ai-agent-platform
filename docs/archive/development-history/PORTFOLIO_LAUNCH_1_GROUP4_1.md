# Portfolio Launch 1 — Group 4.1

Responsive overflow hotfix for the RAG Evaluations admin screen.

## Fixes
- Prevents the admin content flex chain from inheriting wide table minimum widths.
- Constrains evaluation grids and panels with `min-w-0` and bounded width rules.
- Keeps horizontal scrolling local to the evaluation run-history table.
- Allows long evaluation questions and labels to wrap safely.
- Improves the evaluation hero KPI layout on smaller screens.

No backend/API behavior changed.
